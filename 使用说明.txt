番茄新书榜风向标 · 本机使用说明（女频 + 男频双频道）
====================================================

这个工具每天抓取「番茄小说·新书榜」各分类 Top 20-30，
自动做趋势对比（新上榜 / 掉榜 / 排名变化 / 阅读量增长），
再用 AI 生成题材赛道分析，最后给你一个本地看板网页。

现在女频和男频是**两套完全独立的数据**，跑男频不会覆盖女频。


【怎么用 - 就两步】

第 1 步：双击「一键更新.bat」（或「一键更新男频.bat」/「一键更新全部.bat」）
  - 一键更新.bat       → 只更新女频
  - 一键更新男频.bat   → 只更新男频
  - 一键更新全部.bat   → 男女频依次跑完（约 10-18 分钟）
  - 第一次运行会自动装好所有环境（约 5-10 分钟）
  - 之后每次运行会重新抓取当天最新榜单（单频道约 4-8 分钟）
  - 抓取时不要关闭黑窗口，等它出现「Update complete」再关
  - 注意：bat 窗口里的提示文字是英文，这是为了避免 Windows 中文系统解析
    中文 bat 时报错，属正常现象；爬虫和看板里的数据、日志仍然是中文

第 2 步：双击「启动看板.bat」
  - 会自动打开浏览器显示看板
  - 看板右上角有「女频 / 男频」按钮，点一下即可切换频道
  - 看完直接关掉黑窗口即可停止


【AI 分析怎么开】

  项目根目录有个 .env 文件（已经帮你配好 DeepSeek），内容是：

    API_BASE_URL=https://api.deepseek.com/v1
    API_KEY=你的密钥
    API_MODEL=deepseek-v4-flash

  - 换别的模型/服务商，改这三个值即可（任何 OpenAI 兼容接口都行）
  - 不想用 AI：把 .env 删掉或改名，会自动降级为规则统计摘要
  - .env 里有密钥，不要上传到 GitHub（.gitignore 已经忽略它）


【男频为什么以前没有分析？现在修好了什么】

  1. 赛道分组和题材词库原来只有女频一套，男频 19 个分类里只有 3 个能归组
     → 现在男频有 8 个自己的赛道：玄幻仙侠 / 都市超能 / 历史军事 /
       悬疑惊悚 / 科幻末世 / 都市爽文 / 游戏体育 / 衍生同人
  2. 男频原本只有一天数据，脚本直接写「首日数据，暂无趋势对比」
     → 现在首日会按「当前在读总量」给出赛道、分类、题材三层结论
  3. 男女频原来共用同一批输出文件，跑男频会覆盖女频看板
     → 现在完全隔离（见下表）
  4. 男频简介/作者名里还残留 \ue4xx 乱码（字体混淆表是空的）
     → 现在解码会自动回退到女频同款字形表，乱码清零
  5. GitHub Actions 原来只抓女频
     → 现在每天男女频一起抓、一起分析、一起发布

【看板里有什么】

  - index.html    主看板：各分类新书榜 Top30 + 与昨日对比的趋势 + AI 速评
  - trend.html    风向标：近 7/14/30 天趋势，综合赛道 / 具体分类 / 高频题材
  - shorts.html   短篇推荐页
  - book.html     单本书的历史上榜记录
  - api/lastest*/ 纯数据 JSON 接口（可给程序用）


【怎么"顺应潮流"（看趋势的正确姿势）】

  1. 打开 trend.html，先看顶部「全站热点」：AI 会告诉你哪个赛道在读增长最快、
     哪个具体分类在领跑、哪些题材词高频出现
  2. 中间「综合赛道」按阅读增长排序，点具体分类可以直接跳到该分类的多日走势
  3. 下面「上升作品 / 新上榜焦点」是最近几天冲榜最猛的书，点进去能看简介
  4. 「每日风向摘要」是每一天 AI 生成的分类速评，可以翻最近 10 天
  5. 只有一天数据时看的是「当前在读总量」，积累两天后自动切换成「增长」口径

  ⚠️ 注意：阅读量/在读量是平台公开展示的粗略数字，仅用于横向对比，
     不代表真实流量或作品质量。


【把改动推到 GitHub（让线上每天自动更新）】

  双击「推送更新.bat」即可。它会先列出待推送的提交，再执行 push。
  推成功后，GitHub Actions 每天 08:00 会自动抓取男女频并生成 AI 分析。

  如果提示 "Permission ... denied to XXX"（本机登录的 GitHub 账号没有该仓库
  写权限），按提示二选一：
    A) 换成仓库所有者的账号：控制面板 → 用户账户 → 凭据管理器 →
       Windows 凭据 → 删除  git:https://github.com  → 再双击本脚本重新登录
    B) 或者在 GitHub 仓库 Settings → Collaborators 里把当前账号加为协作者

  注：本地是浅克隆（--depth=1，为省流量）。若 push 报
  "shallow update not allowed"，先执行 git fetch --unshallow 再推。


【常见问题】

  1. 抓取失败/榜单为空？
     → 番茄网页改版了，或当天被风控。直接再跑一次对应的一键更新脚本。
  2. 男频/女频数据串了？
     → 看板右上角确认频道；URL 里的 ?gender=male 决定频道，选择会被记住。
  3. 想让电脑每天 8 点自动更新？
     → 在 Windows「任务计划程序」里新建任务，触发器选每天 08:00，
       操作指向「一键更新全部.bat」即可。
  4. 只想重算 AI 分析（不重新抓取）？
     → 命令行执行：
       venv\Scripts\python.exe scripts\build_latest.py --gender male --force
       venv\Scripts\python.exe scripts\build_latest.py --gender female --force
     → 只想重算统计口径、不调用 AI（省钱、断网也能跑）：把 --force 换成 --no-ai
       （已有的 AI 总结会被保留，不会被规则文案覆盖）
  5. 抓到一半中断了？
     → 直接重跑。爬虫按分类断点续抓，已完成的分类会跳过。
